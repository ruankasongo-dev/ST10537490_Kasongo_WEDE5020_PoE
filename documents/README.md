# National Zoological Garden Website – WEDE5020

## 1. Project Overview
This website project is based ONLY on the National Zoological Garden of South Africa (NZG) in Pretoria. The purpose is to present clear, relevant and organised information about wildlife, conservation, education, visitor information and enquiries.

The website is an academic web-development project. Current visitor information, prices, opening times and booking arrangements should always be confirmed through official SANBI information.

## 2. Goals and Objectives

### Goal
To create an informative, user-friendly and responsive website that introduces the National Zoological Garden and helps visitors find useful information about wildlife, conservation, education, services and contact/enquiry options.

### Objectives
1. Present the National Zoological Garden clearly and professionally.
2. Organise information into logical pages.
3. Provide relevant information about wildlife, education and conservation.
4. Give visitors a clear way to make an enquiry.
5. Provide contact and location information.
6. Use consistent navigation throughout the website.
7. Use responsive design for desktop, tablet and mobile screens.
8. Keep HTML structure separate from CSS presentation.
9. Use meaningful comments to explain important code sections.
10. Maintain documentation, a changelog and Harvard-style references.

## 3. Proposed Features and Functionality

- Home page with a strong introduction and call-to-action.
- About Us page describing the NZG's purpose and role.
- Services page covering wildlife, education, public engagement and events/functions.
- Enquiry form for visitor questions.
- Contact page with organisation and location information.
- Wildlife photographs with descriptive alternative text.
- Consistent navigation and footer.
- Responsive layout using CSS media queries.
- Structured tables for information.
- Clear headings and content sections.
- External CSS stylesheet.
- Accessible form labels.
- Links between all five pages.

## Part 3 – Enhancing Functionality and SEO

### Functionality
- JavaScript hamburger navigation with accessible expanded/collapsed state.
- Search bar filters matching content sections/cards on the current page.
- Image lightbox opens content images in a larger dialog.
- Enquiry and contact forms use browser-side validation and accessible feedback.
- Forms are demo-only and do not transmit data; a live deployment needs a secure server endpoint.

### SEO and accessibility
- Unique page titles and meta descriptions.
- Robots directives, canonical link placeholders, `robots.txt` and `sitemap.xml`.
- Semantic main landmark, skip-to-content link, descriptive image alt text and lazy loading.
- Internal links, mobile responsive design, visible keyboard focus and reduced-motion support.
- Replace every `REPLACE-WITH-YOUR-GITHUB-PAGES-URL` placeholder before publishing.
- The search bar filters the current page only; it is not a whole-site search index.
