# National Zoological Garden Website
## 1. Project Overview
is based on the National Zoological Garden of South Africa (NZG) in Pretoria. Its purpose is to present clear relevent and organised information about wildlife. This website is an academic one. 
## 2. Goals and Objectives
### Goal
To create an informative, user-friendly and responsive website that introduces the National Zoological Garden and helps visitors find usefull information about wildlife, education, services, and enquiry options.
### Objectives
1. Present the National Zoological Garden clearly and professionally.
2. Organise information into logical pages.
3. Provide relevant information.
4. Give visitors a clear way to make an enquiry.
5. Provide contact and location information.
6. Use consistent navigation throughout the website.
7. Use responsive design for desktop, tablet and mobile screens.
8. Keep HTML structure separate from CSS presentation.
9. Use meaningful comments to explain important code sections.
## 3. Proposed Features and Functionality
- Home page with a strong introduction and call-to-action.
- About Us page describing the NZG's mission and vision
- Services page covering wildlife, education, conservation and animals
- Enquiry form for visitor questions.
- Contact page with organisation and location information.
- Wildlife photographs with descriptive alternative text.
- Consistent navigation and footer.
- Responsive layout using CSS media queries.
- Structured tables for information.
- Clear headings and content sections.
- External CSS stylesheet.
- Accessible form labels.
- Links between all five pages.

## 10. Code Comments

Comments are included in the HTML and CSS to explain major sections.

Examples include:

```html
<!-- Header contains the site identity and main navigation. -->
```

and:

```css
/* Responsive design */
```

The CSS also identifies the required selector types:
- Tag selectors
- ID selectors
- Class selectors
- Compound selectors
- Grouping selectors
## 11. Version Control and Descriptive Commits

Actual Git commits should be made regularly during development. Suggested commit messages are:

1. `Initial National Zoological Garden website structure`
2. `Add NZG home and about page content`
3. `Add services and visitor information`
4. `Add enquiry and contact forms`
5. `Move styling to external CSS stylesheet`
6. `Add responsive CSS media queries`

## 12. Testing Checklist

- Test every navigation link.
- Confirm all five HTML pages open correctly.
- Confirm all images load.
- Confirm image alternative text is present.
- Test enquiry and contact forms.
- Test the website at desktop, tablet and mobile widths.
- Check the responsive media queries.
- Check HTML and CSS for errors.
- Check spelling and grammar.
- Confirm README and CHANGELOG are included.
- Confirm the project contains only National Zoological Garden content.
