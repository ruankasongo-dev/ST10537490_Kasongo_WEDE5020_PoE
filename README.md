# National Zoological Garden Website — Organised Project

This project combines the National Zoological Garden website files into one organised folder structure. HTML pages are kept at the project root; CSS, JavaScript, and images each have their own folder.

## Folder structure

```text
ST10537490_Kasongo_NZG_Organised_Project/
├── Index.html
├── About.html
├── Services.html
├── Enquiry.html
├── Contact.html
├── css/
│   └── style.css
├── js/
│   └── site.js
├── images/
│   ├── education.jpg
│   ├── elephant.jpg
│   ├── giraffe.jpg
│   ├── lion.jpg
│   ├── rhino.jpg
│   ├── zebra.jpg
│   └── zoo.jpg
└── documents/
    ├── README.md (original, if supplied)
    ├── CHANGELOG.md (original, if supplied)
    ├── SEO-CHECKLIST.md (if supplied)
    ├── robots.txt (if supplied)
    ├── sitemap.xml (if supplied)
    └── Web Development POE 1.docx (if supplied)
```

## Open in VS Code
1. Extract the ZIP file.
2. In VS Code, select **File → Open Folder** and choose this folder.
3. Open `Index.html` in a browser, or use the Live Server extension.
4. Keep the `css`, `js`, and `images` folder names unchanged because the HTML pages link to them.

Note: JavaScript is written in `.js` files (not Java `.java` files). The supplied site's script is `js/site.js`.
